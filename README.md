# CSharp-Reflections

## Description  
This repository is dedicated to mastering **Reflection in C#**, enabling runtime inspection, modification, and dynamic invocation of types, members, and metadata.  
It provides hands-on implementations to help developers understand how C# applications can **analyze, explore, and manipulate themselves during execution**.

---

## Tech Stack  
- **Language:** C#  
- **Platform:** .NET 8  
- **IDE:** Visual Studio Code  
- **Version Control:** Git & GitHub  

---

## Repository Structure & Branches  

### `reflection` Branch  
This branch explores the complete lifecycle of Reflection with real-world scenarios:

- Inspecting classes, methods, fields, and constructors at runtime  
- Accessing private and static members  
- Dynamically creating objects and invoking methods  
- Working with custom attributes through Reflection  
- Implementing advanced utilities such as execution timing and object-to-JSON conversion  

**Purpose:**  
> To develop a deep understanding of runtime metadata inspection and build highly dynamic, extensible C# applications using Reflection.

##  Learning Outcomes  

By working through this repository, you will:

- Develop a deep understanding of runtime type inspection in C#

- Dynamically invoke methods and instantiate objects

- Apply Reflection in advanced, real-world engineering scenarios
